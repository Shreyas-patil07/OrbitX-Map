# OrbitX-Map

> **Earth Observation & Disaster Intelligence Platform**

OrbitX turns multi-temporal satellite data (Sentinel-1 SAR and Sentinel-2 optical imagery), terrain elevation, and AI-driven change detection into a single operational map for emergency response.

---

## Overview

- **SAR & Optical Fusion**: Leverages Sentinel-1 synthetic aperture radar and Sentinel-2 multispectral data to assess ground displacement, flood boundaries, and post-event anomalies.
- **AI Damage Assessment**: Highlights affected infrastructure, active risk corridors, and road access viability.
- **Responsive Dashboard**: Built with high-fidelity visual styling, dark glassmorphism, responsive telemetry feeds, and interactive map intelligence controls.

---

## Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Vanilla CSS (Tailwind scale compatible, custom design tokens, dark mode)
- **Tooling**: Oxlint

---

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Running Locally

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.
